HR Analytics

📌 Project Overview

This project analyzes employee data to understand **employee attrition, workforce demographics, income, job satisfaction, and work-life balance**. The analysis was performed using Excel, Power BI, and Tableau to identify HR trends and create interactive dashboards.

🎯 Objectives

* Analyze employee attrition patterns
* Identify departments with higher attrition
* Analyze employee income and job-related factors
* Understand workforce demographics
* Examine job satisfaction and work-life balance
* Identify key factors related to employee attrition

🛠️ Tools Used

* **Microsoft Excel** – Data cleaning, preparation, and analysis
* **Power BI** – Data modeling, DAX, KPI analysis, and interactive dashboard
* **Tableau** – Data visualization and interactive dashboard

📊 Key Analysis

* Department-wise attrition
* Attrition by job role
* Income analysis
* Employee demographics
* Job satisfaction
* Work-life balance
* Years at company
* Years since last promotion

📈 Dashboard

Interactive Power BI and Tableau dashboards were created to analyze employee attrition and workforce trends using key HR metrics and filters.

💡 Key Insights

The analysis highlights patterns in employee attrition and provides insights into factors such as department, income, job satisfaction, work-life balance, experience, and promotion history.

 📂 Project Files

* `HR_Analytics.xlsx` – Dataset and Excel analysis
* `HR_Analytics.pbix` – Power BI dashboard
* `HR_Analytics.twbx` – Tableau dashboard
